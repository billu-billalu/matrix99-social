## Must know
- A relation is a function if each input has exactly one output; on a graph, use the vertical-line test (10.1 §1.2).
- Know domain and range for each function type (10.1 §1.1–1.2, 11.1 §1.3).
- Composition applies one function to another's output, and generally f(g(x)) ≠ g(f(x)) (11.1 §1.4).
- The graph of an inverse is the reflection of the function in y = x (11.1 §1.5).
- Remainder theorem: dividing P(x) by (x − a) leaves remainder P(a). Factor theorem: (x − a) is a factor if P(a) = 0 (10.2 §2.3).
- Rational functions have vertical, horizontal or oblique asymptotes (11.2 §2.3).
- Exponential and logarithmic functions are inverses of each other (10.3 §3.5).

## Formulas
- log(xy) = log x + log y; log(x/y) = log x − log y; log(x^n) = n log x (10.3 §3.1)
- Change of base: log_b x = log_a x ÷ log_a b (10.3 §3.1)
- y = b^x means x = log_b y (10.3 §3.5)
