# Math Ch12 Linear Programming

Linear programming finds the best outcome under limits. The method is always the same: write it, graph it, test the corners.

## Reading path
- [ ] Recap [[Math 9.4 Solving Inequalities]] §4.2 (graphing systems of inequalities)
- [ ] [[Math 12.4 Introduction to Linear Programming]] §4.1–4.3

## Must know
- Graph each inequality and find the feasible region where they overlap (9.4 §4.2, 12.4 §4.1).
- Write the objective function and constraints from the word problem (12.4 §4.3).
- The maximum or minimum occurs at a corner point of the feasible region (12.4 §4.2).

## Make
- Template: variables → objective → constraints → graph → corner points → evaluate
