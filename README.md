# matrix99-social

A free Obsidian study vault for the Ethiopian EUEE, social-science stream. It maps the 2023 new-curriculum textbooks for Grades 9–12 into chapters you can study in order.

**Included:** 128 unit notes, 53 chapter guides, 26 cross-subject bridges, a study plan, an error log, a history timeline and a formula sheet. Every unit has a checklist and key terms, and every chapter guide adds must-know points and self-tests. Math chapters also include practice problems with answers.

**Not included yet:** English, Scholastic Aptitude and past-paper weighting. Citizenship is left out because it is no longer tested in this stream.

## Setup
1. Install [Obsidian](https://obsidian.md).
2. Download this repo (Code → Download ZIP) or clone it.
3. The textbooks are in `sources/books/`. Two are too large for GitHub's file limit, so download `math-g11.pdf` and `math-g12.pdf` from this repo's **Releases** page and put them in that folder.
4. In Obsidian, choose **Open folder as vault** and open this folder.
5. Start at `00-home/dashboard.md`.

## How to use it
Follow the study plan. Each chapter guide lists what to read and what you must know, then tests you. In each unit note, study **CORE** sections closely, read **SKIM** sections quickly, and read the linked section first for **BUILDS**. Check `practice/book-checks.md` for errors in the textbooks.

Update `status` in each unit note as you go, and log every wrong answer in `practice/error-log.md`.

## Accuracy
Section numbers were checked against the textbook text. CORE and SKIM tags are provisional judgments based on comparing the books. They have not yet been checked against past papers, so don't skip a SKIM section entirely.
